# PROG209 – Basic Interactive GUI

**Module:** PROG209 Event Driven Programming
**Student:** Jaria Bah
**University:** Limkokwing University of Creative Technology, Sierra Leone

## About
A basic interactive GUI application built with Java Swing. It opens an 800 × 800 window titled "Java Swing Assignment" with a welcome message, a custom application icon, and two interactive buttons.

## Features
- **JFrame** – main window with a title, 800 × 800 size, and close-on-exit
- **JPanel** – custom `MyPanel` class that extends `JPanel` (inheritance)
- **JLabel** – displays the welcome message
- **ImageIcon** – custom "JB" application icon
- **Constructors** – used to set up the panel and the main window
- **Event handling** – "Change Text" changes the label text, and "Change Background" gives the panel a random colour

## Project Structure
- `src/SwingAssignment.java` – application source code
- `src/icon.png` – custom application icon

## How to Run
1. Open the project in IntelliJ IDEA.
2. Open `src/SwingAssignment.java`.
3. Click the green Run button next to the `main` method.
